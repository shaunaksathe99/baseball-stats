# Add your generated pages here

Create a folder for each page or small project, for example:

```text
pages/
└── season-dashboard/
    ├── index.html
    └── dashboard.css
```

Use each folder's `index.html` as its entry point. Upload files through GitHub with **Add file → Upload files**, or commit them with Git. Add a link to each new page from the root `index.html` so visitors can find it.
