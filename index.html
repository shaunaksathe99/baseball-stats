Bring in a new page

Ask Claude for a self-contained HTML page or a set of files, then add them to this repository.

  1. Create a folder under pages/, such as pages/season-dashboard/.
  2. Upload the generated page as index.html in that folder.
  3. Place images, CSS, or JavaScript in assets/ (or alongside the page).
  4. Add a link to the page in this homepage's “Explore the site” section.
